# cosscom/homebrew-tap

Homebrew formulae for [coss.com](https://coss.com).

```sh
brew install cosscom/tap/coss
```

`coss` is the coss.com command line: sign in, send test emails, follow your environment's log,
receive webhook events on localhost and call any endpoint of the API. Guide:
[coss.com/docs/cli](https://coss.com/docs/cli).

`Formula/coss.rb` is written by the release workflow of
[cosscom/coss](https://github.com/cosscom/coss/blob/main/.github/workflows/release.yml) for every
`coss-cli` release, from the release's own `SHA256SUMS`. Don't edit it by hand: changes are
overwritten by the next release. Issues and pull requests go to
[cosscom/coss](https://github.com/cosscom/coss/issues).
